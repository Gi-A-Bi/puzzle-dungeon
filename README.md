# 두뇌 퍼즐 던전 (Puzzle Dungeon)

초등학생을 위한 1~2인용 두뇌 퍼즐 웹게임입니다. 디벗(교육용 태블릿) 브라우저에서 링크만 열면 바로 실행되는 **단일 HTML 파일**로 만듭니다.

던전을 한 층씩 내려가며 방마다 나오는 사고력 퍼즐(패턴 찾기, 불빛 기억, 그림 스도쿠, 로봇 길 찾기 등)을 풀고 별을 모으는 게임입니다.

## 현재 상태

- 2026-10-22: 콘셉트 확정(B안, 퍼즐 던전) 후 1차(MVP) 구현 완료. `index.html` 하나로 동작합니다.
- 1차에 들어간 것: 타이틀·난이도 선택, 캐릭터 4종, 3층 × 3방, 퍼즐 4종(패턴 찾기, 불빛 기억, 그림 스도쿠, 로봇 길 찾기), 별 3개 평가, 힌트, 오답 3회 시 정답 공개, 층 클리어 보물상자, 결과 트로피, 소리 on/off
- 2026-10-22: 이모지·CSS 그림을 GPT로 만든 일러스트(`assets/`)로 교체. 캐릭터는 정답·오답 때 표정이 바뀜
- 설계 문서: [docs/DESIGN.md](docs/DESIGN.md)

## 실행 방법

- 가장 간단한 방법: `index.html`을 브라우저로 열면 바로 실행됩니다.
- 로컬 서버로 열고 싶으면 프로젝트 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8765`에 접속합니다.

```bash
python -m http.server 8765
```

## 기술 전제

- HTML + CSS + 순수 JavaScript 한 파일 (`index.html`), 외부 라이브러리 없음
- 애니메이션은 CSS 애니메이션 + 간단한 캔버스
- 효과음은 Web Audio API로 코드에서 생성 (음원 파일 없음)
- 서버·로그인 없음. 최고 기록만 기기 안(localStorage)에 저장
- 터치 중심 UI: 터치 영역 60px 이상, 글씨 20px 이상, 가로/세로 모두 대응

## 폴더 구조

```
index.html             게임 본체 (외부 라이브러리 없음)
assets/                게임에 쓰는 그림 (WebP, 총 1.3MB)
  bg/                  타이틀 입구, 층별 배경 3종
  char/                캐릭터 4종 × 기본·기쁨·놀람
  ui/                  문, 보물상자, 트로피, 별, 횃불, 전구, 수정구슬
  fruit/               스도쿠 과일 6종
  robot/               로봇, 보석, 바위
  original/            GPT로 만든 원본 PNG (용량이 커서 git에서 제외, 로컬 보관)
docs/DESIGN.md         설계 문서
docs/IMAGE_PROMPTS.md  그림 생성에 쓴 프롬프트
```
