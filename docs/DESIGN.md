# 두뇌 퍼즐 던전 설계안

작성일: 2026-10-22
상태: 콘셉트 확정, 코딩 전

## 1. 개요

- 대상: 초등학생 (1~6학년, 난이도 3단계로 대응)
- 인원: 1인 기본, 같은 기기에서 2인 협동
- 환경: 디벗(교육용 태블릿) 브라우저, 터치 중심, 가로/세로 대응
- 형식: 던전을 한 층씩 내려가며 방마다 사고력 퍼즐을 푸는 보드게임형 두뇌 게임
- 교육 목표: 패턴 추론, 공간 지각, 기억력, 논리 추리, 수 감각, 코딩적 사고

## 3. 던전 구조

- 총 5층, 한 층에 일반 방 3개 + 보스 방 1개. 방 하나 = 퍼즐 하나
- 한 층 클리어에 5분 안팎 → 수업 시간에 맞춰 "오늘은 2층까지"처럼 끊어서 사용
- 층 테마 (내려갈수록 배경색·효과음 변화)
  1. 이끼 동굴
  2. 얼음 동굴
  3. 용암 동굴
  4. 수정 동굴
  5. 용의 보물방
- 보스 방: 그 층에서 나온 퍼즐 중 하나를 조금 큰 버전으로 출제. 클리어하면 보물상자가 열리며 별이 튀어나오고 다음 층 문이 열림

## 4. 퍼즐 목록

1차(MVP)에는 1~4번만 넣고, 5~8번은 2차에 추가한다.

| # | 이름 | 내용 | 기르는 힘 | 난이도 파라미터 |
|---|---|---|---|---|
| 1 | 패턴 찾기 | 도형·색 수열을 보고 다음에 올 것을 4개 중 고르기. 글자 없이 그림만 | 패턴 추론 | 수열 길이 3/4/5, 규칙 종류(색만 / 색+모양 / 색+모양+크기) |
| 2 | 불빛 기억 | 불빛이 켜지는 순서를 따라 누르기. 성공할수록 한 단계씩 길어짐 | 기억력 | 버튼 수 4/6/9, 목표 단계 4/6/8 |
| 3 | 그림 스도쿠 | 과일 그림을 겹치지 않게 채우기 | 논리 | 격자 4×4(빈칸 4) / 4×4(빈칸 7) / 6×6 |
| 4 | 로봇 길 찾기 | "앞으로·왼쪽·오른쪽" 블록을 끌어다 놓아 로봇을 보물까지 보내기 | 코딩적 사고 | 격자 3×3 / 4×4 / 5×5, 장애물 유무, 블록 수 제한 |
| 5 | 저울 추리 | 저울 그림 2~3개를 보고 가장 무거운 동물 고르기 | 논리 추리 | 저울 2/3/4개, 동물 3/4/5종 |
| 6 | 블록 채우기 | 테트리스 조각을 돌려서 빈 공간을 정확히 채우기 | 공간 지각 | 빈 공간 크기, 조각 수 2/3/4 |
| 7 | 합 맞추기 | 숫자 칸을 짝지어 목표 합 만들기 | 수 감각 | 목표 합 10/20/50, 칸 수 6/8/12 |
| 8 | 누구일까 추리 | 말풍선 힌트 3개로 모자 주인 맞추기 (고학년 전용) | 조건 추리 | 인물 3/4/5명, 힌트 수 |

퍼즐 공통 규칙:
- 글 읽기 최소화. 설명은 아이콘 + 짧은 말풍선, 처음 1회만 튜토리얼
- 모든 조작은 터치(탭·드래그)로 가능
- 각 퍼즐은 `generate(level)` → 문제 데이터, `check(answer)` → 정답 여부 형태로 독립 모듈화

## 5. 점수와 피드백

- **별 3개 평가** (방마다)
  - 힌트 없이 한 번에 성공: ★★★
  - 힌트 1회 또는 두 번째 시도 성공: ★★
  - 그 외 성공: ★
  - 3회 실패: 정답을 보여주고 다음 방으로 진행 (별 0). 막혀서 그만두는 아이가 없게 하는 장치
- **힌트**: 전구 아이콘, 방마다 1회. 보기 하나 지우기 또는 정답 칸 깜빡임
- **타이머**: 기본 꺼짐. 켜면 제한 시간 안에 풀 때 보너스 별. 저학년은 끄고 사용 권장
- **연출**
  - 정답: 폭죽 + 캐릭터 점프 + 경쾌한 효과음
  - 오답: 캐릭터가 "앗!" 하고 횃불이 흔들림. 벌칙 느낌 없음
  - 층 클리어: 보물상자 열림, 별이 튀어나와 합산, 다음 층 문 열림
- **배지** (6개 정도)
  - 번뜩이: 연속 3방 ★★★
  - 탐험왕: 힌트 없이 한 층 클리어
  - 용사: 보스 방 첫 시도 성공
  - 끈기왕: 3회 실패 후에도 다음 층까지 진행
  - 기억천재: 불빛 기억 최고 단계 도달
  - 완주: 5층 모두 클리어

## 6. 모드

- **1인**: 혼자 내려가며 별을 모으고, 최종 화면에서 별 합계로 동·은·금 트로피. 기기 안에 최고 기록(도달 층, 별 수) 저장
- **2인 협동** (기본): 같은 기기에서 방 하나씩 번갈아 풀고 별을 합쳐 함께 내려감. 짝 활동에 맞고 지는 아이가 생기지 않음
- **2인 대결** (2차): 같은 퍼즐을 번갈아 풀어 별·시간 비교

## 7. 화면 흐름

1. **타이틀**: 던전 입구 그림, 시작 버튼, 소리 on/off, 난이도 선택
2. **인원·캐릭터 선택**: 1인/2인, 탐험가 캐릭터 4종 (여우, 펭귄, 고양이, 공룡)
3. **던전 맵**: 층 단면도, 잠긴 문이 순서대로 열림, 현재 위치에 캐릭터가 횃불을 들고 서 있음
4. **방 화면**: 퍼즐 UI + 힌트 버튼 + 현재 별 + 진행 표시(몇 층 몇 번째 방)
5. **층 클리어**: 보물상자, 별 합계, 획득 배지
6. **최종 결과**: 트로피, 이름 입력, 다시 하기

## 8. 교사 설정

톱니 아이콘을 길게 눌러야 열리게 해서 학생이 건드리지 않게 한다.

- 난이도 (쉬움/보통/어려움)
- 타이머 on/off
- 오늘 플레이할 층 수 (1~5)
- 퍼즐 종류 켜고 끄기
- 소리 on/off
- 최고 기록 초기화

## 9. 기술 설계

- 파일: `index.html` 하나. 안에 `<style>`, `<script>` 포함
- 화면 전환: 각 화면을 `<section>`으로 두고 CSS 클래스로 표시/숨김 + 전환 애니메이션
- 상태 객체 예시

```js
state = {
  mode: 'solo' | 'coop',
  difficulty: 'easy' | 'normal' | 'hard',
  players: [{ name, character, stars }],
  floor: 1, room: 1,
  settings: { sound, timer, floors, puzzlesEnabled }
}
```

- 퍼즐 모듈 인터페이스: `{ id, name, generate(level), render(container, data, onAnswer), check(data, answer), hint(data) }`
- 효과음: Web Audio로 짧은 톤 조합 (정답, 오답, 버튼, 문 열림, 보물상자)
- 저장: `localStorage`에 최고 기록과 교사 설정만
- 반응형: `vmin` 단위 중심, 가로/세로 모두에서 퍼즐 영역이 화면 안에 들어오도록

## 10. 로드맵

- **1차 (MVP)**: 타이틀, 캐릭터 선택, 3층 × 3방, 퍼즐 1~4번, 별·힌트, 층 클리어 연출, 1인 모드, 소리 on/off
- **2차**: 퍼즐 5~8번, 보스 방, 2인 협동, 배지, 최고 기록, 교사 설정 전체
- **3차 (검토)**: 2인 대결, 층 테마 5개 완성, 튜토리얼 다듬기

## 11. 미결정 사항

- 게임 이름 (가칭 "두뇌 퍼즐 던전")
- 1차에 넣을 퍼즐 4종이 1~4번으로 괜찮은지
- 2인 모드를 협동 기본으로 갈지, 대결도 1차에 넣을지
